# AD&D 2e Character Builder — Beta 1.0

Versión web basada en HojaV31_27_BUILDER_BLANCO_IMPRESION_PROTEGIDA.html.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre Settings → Pages.
4. En “Build and deployment”, selecciona “Deploy from a branch”.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la dirección pública del sitio.

## Importante
- El autosave sigue usando localStorage: cada navegador/dispositivo conserva sus propios datos.
- Los archivos `.adnd2` siguen siendo el medio portátil para exportar/importar personajes.
- La impresión conserva el sistema de la Beta 1.0.
- `html2canvas` continúa cargándose desde jsDelivr; por ello la función de impresión requiere conexión a Internet.
- La fuente Cinzel Decorative continúa cargándose desde Google Fonts cuando está disponible.

No se ha modificado la lógica del personaje, cálculos, posiciones ni sistema de guardado.
